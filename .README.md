# JSON-Translator-Toolkit

**[English](#english) | [Русский](#русский)**

## English

Scripts for translating text in Unity games: extract the text, translate it as plain TXT files, pack it back.

You need Python and `UnityPy`. The `tt_*.py` scripts also need `TypeTreeGeneratorAPI`, and `collect_dumps.py` needs .NET and Il2CppDumper.
Run scripts from the project folder: `python script_name.py`.

### JSON dialogue (TextAsset)

1. Put the game files into `Unity_Original`.
2. `unity_extract.py` extracts TextAssets to `Files/Original`.
3. `export.py` pulls the lines into `Files/OriginalStringOnly`.
4. Copy them to `Files/ModifiedStringOnly` and translate.
5. `assets_checkNEW.py` checks the translation.
6. `import.py` builds the JSON files in `Files/Output/Ready`.
7. `unity_pack.py` writes the finished files to `Unity_Modded`.

Only non-empty string fields whose name ends with `text` are extracted. Exclude extra fields or values in `ignore_list.txt`.
Plain text files (`Credits.txt`, `anonposts.txt`) work too: one line in the file is one line to translate.
Files without a translation stay unchanged.

### Dialogue inside level files

1. Put `level0`, `level1`, etc. into `Level_Original`.
2. `python 'level_extract(1).py'`
3. Copy `Files/LevelOriginalStringOnly` to `Files/LevelModifiedStringOnly` and translate.
4. `level_checkNEW.py`, then `python level_packNEW..py`.
5. The result goes to `Level_Modded`.

This only works for dialogue followed by an `ExtraData` marker in the file.

### Other fields (via Unity type trees)

1. Write the game path into `GameDir.txt`.
2. Put Il2CppDumper into `Tools/Il2CppDumper` and run `collect_dumps.py` (you can pass the game path as an argument instead).
3. `tt_extract.py`
4. Copy `Files/TTOriginalStringOnly` to `Files/TTModifiedStringOnly` and translate.
5. `tt_pack.py` writes the result to `Level_Modded`.

`tt_fields.txt` sets which fields to take:
- `+word` takes fields whose name contains this word (case-insensitive);
- `-field` excludes the field with exactly this name.

After editing this file, extract the text again.

**Important for both level-file methods:** if `Level_Modded` already has a packed file, the script adds to it instead of starting from scratch. So pack the dialogue first, then the fields. To start over, clear `Level_Modded`. Don't mix files from different game versions.

### Translation rules

- One TXT line is one line of dialogue. Don't change the number or order of lines.
- Write a line break inside a line as `\n`, carriage return as `\r`, backslash as `\\`.
- Leave empty lines in place. An empty translation of a non-empty line is an error.
- Don't touch tags `<...>`, `{...}` and `[...]`.

If something is wrong, packing stops with an error. Fix the translation and run it again.
After a failed run, don't use the output folder: it may contain old files.

The scripts don't install anything into the game; copy the files manually.

### Other

- `.Extra/importWithTab.py` is an old standalone import (`TxtFolder` + `TxtFolderTranslated` → `TxtFolderReady`), not part of the main workflow.
- `ModifiedStringOnly_N` folders from older versions are no longer used.

## Русский

Скрипты для перевода текстов в играх на Unity: достаём текст, переводим в обычных TXT, собираем обратно.

Нужен Python и `UnityPy`. Для `tt_*.py` ещё `TypeTreeGeneratorAPI`, а для `collect_dumps.py` — .NET и Il2CppDumper.
Скрипты запускаются из папки проекта: `python имя_скрипта.py`.

### Диалоги в JSON (TextAsset)

1. Кладёшь файлы игры в `Unity_Original`.
2. `unity_extract.py` — достаёт TextAsset в `Files/Original`.
3. `export.py` — вытаскивает реплики в `Files/OriginalStringOnly`.
4. Копируешь их в `Files/ModifiedStringOnly` и переводишь.
5. `assets_checkNEW.py` — проверка.
6. `import.py` — собирает JSON в `Files/Output/Ready`.
7. `unity_pack.py` — готовые файлы в `Unity_Modded`.

Берутся непустые строковые поля, имя которых заканчивается на `text`. Лишние поля и значения можно исключить в `ignore_list.txt`.
Обычные текстовые файлы (`Credits.txt`, `anonposts.txt`) тоже поддерживаются: одна строка файла — одна строка перевода.
Если файл не переведён, остаётся оригинал.

### Диалоги внутри level-файлов

1. Кладёшь `level0`, `level1` и т. д. в `Level_Original`.
2. `python 'level_extract(1).py'`
3. Копируешь `Files/LevelOriginalStringOnly` в `Files/LevelModifiedStringOnly` и переводишь.
4. `level_checkNEW.py`, затем `python level_packNEW..py`.
5. Результат — в `Level_Modded`.

Работает только для диалогов, после которых в файле идёт маркер `ExtraData`.

### Остальные поля (через схемы Unity)

1. Пишешь путь к игре в `GameDir.txt`.
2. Кладёшь Il2CppDumper в `Tools/Il2CppDumper` и запускаешь `collect_dumps.py` (путь к игре можно передать аргументом).
3. `tt_extract.py`
4. Копируешь `Files/TTOriginalStringOnly` в `Files/TTModifiedStringOnly` и переводишь.
5. `tt_pack.py` — результат в `Level_Modded`.

Какие поля брать, задаётся в `tt_fields.txt`:
- `+слово` — брать поля, в имени которых есть это слово (регистр не важен);
- `-поле` — исключить поле с точно таким именем.

После правки этого файла текст нужно извлечь заново.

**Важно для обоих способов с level-файлами:** если в `Level_Modded` уже лежит собранный файл, скрипт дописывает в него, а не собирает с нуля. Поэтому сначала собирай диалоги, потом поля. Чтобы начать заново, очисти `Level_Modded`. Не смешивай файлы разных версий игры.

### Правила перевода

- Одна строка TXT — одна реплика. Количество и порядок строк менять нельзя.
- Перенос строки внутри реплики пишется как `\n`, `\r` — как `\r`, обратный слеш — как `\\`.
- Пустые строки оставляй на месте. Пустой перевод непустой реплики считается ошибкой.
- Теги `<...>`, `{...}` и `[...]` не трогай.

Если что-то не так, сборка остановится с ошибкой. Исправь перевод и запусти снова.
После неудачной сборки не бери файлы из папки результата: там могут остаться старые.

В игру файлы скрипты не ставят, это делается вручную.

### Прочее

- `.Extra/importWithTab.py` — старый отдельный импорт (`TxtFolder` + `TxtFolderTranslated` → `TxtFolderReady`), в основной процесс не входит.
- Папки `ModifiedStringOnly_N` от прошлых версий больше не используются.
